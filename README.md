# WebApp Gastos Quincenales

Esta es una aplicación web ligera para registrar gastos y ahorro quincenalmente. Está diseñada para ejecutarse en el teléfono usando el navegador, con los datos guardados localmente en IndexedDB.

## Características

- Seleccionar y crear quincenas por año, mes y periodo (1 o 2).
- Registrar conceptos como gasto o ahorro.
- Guardar presupuesto inicial y el consumo progresivo.
- Ver total presupuestado, gastado, restante y ahorrado.
- Hacer clic en un concepto para ver el detalle y agregar movimientos.
- Almacenamiento local persistente.

## Cómo usar

1. Abre `index.html` en tu navegador.
2. Crea una quincena nueva o usa la quincena automática inicial.
3. Agrega conceptos y registra los movimientos de consumo.
4. Revisa el detalle y el saldo restante de cada concepto.
